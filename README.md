# ML CI/CD Homework Project

Проект для ДЗ по модулю "CI/CD для ML".

## 1. Описание

Используется датасет Iris (классификация). Проект демонстрирует:

- загрузку и подготовку данных;
- обучение модели RandomForestClassifier;
- логирование эксперимента в MLflow;
- проверку качества данных с помощью Deepchecks;
- анализ дрейфа данных с помощью Evidently;
- интеграцию с GitHub Actions и GitLab CI;
- развёртывание в Docker-контейнере.
